# Security policy

Report a vulnerability in this repository or in the demo it describes privately, by email to
[hello@ihaveasegway.com](mailto:hello@ihaveasegway.com). Please do not open a public issue or pull
request for it.

Say what you found, where, and how to reproduce it. The same address is in the site's
[security.txt](https://ihaveasegway.com/.well-known/security.txt).
